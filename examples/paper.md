# A small note on primal–dual certificates

This is a **local demonstration**, not a research contribution submitted to the archive.

For a cost matrix $C$, a permutation $\pi$ and feasible dual potentials $u,v$ satisfy

$$\sum_i C_{i,\pi(i)} \geq \sum_i u_i + \sum_j v_j.$$

Equality certifies an optimal assignment. The platform checks this property for a
sampled admission problem; it does **not** establish correctness of a paper.
